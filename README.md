## 📌 Overview

**MetaCSV Studio** brings the web-based CSV metadata tool directly to your desktop. Built for performance, privacy, and offline productivity, MetaCSV Studio allows data analysts, developers, and researchers to view, edit, clean, and export CSV files and their accompanying metadata without uploading data to external servers.

This repository hosts all stable binary distributions, installer setups, and auto-update assets for **Windows**, **macOS**, and **Linux**.

---

## ✨ Key Features

- ⚡ **High-Performance CSV Parsing:** Smoothly handle large CSV datasets with minimal RAM consumption.
- 🏷️ **Schema & Metadata Management:** Easily define data types, descriptions, tags, and validation rules for columns.
- 🔒 **100% Offline & Private:** All data processing stays local on your machine.
- 🎨 **Modern & Intuitive UI:** Native dark/light mode support, search filtering, and clean table interfaces.
- 🛠️ **Export Options:** Export enriched data and metadata schemas in CSV, JSON, and custom formats.
- 🔄 **Cross-Platform:** Native builds available across all major operating systems.

## 📦 Downloads & Installation

To install MetaCSV Studio on your system, grab the latest binary from the **[Releases Page](https://github.com/Hasinur3813/metacsv-studio-releases/releases/latest)**.

| Operating System | File / Format | Installation Note |
| :--- | :--- | :--- |
| **Windows** | `.exe` / `.msi` | Download and run the setup wizard. |
| **macOS** | `.dmg` / `.app` | Open the `.dmg` and drag MetaCSV Studio to your `Applications` folder. |
| **Linux** | `.AppImage` / `.deb` | Make `.AppImage` executable (`chmod +x`) and run, or install via `dpkg -i`. |

## 🚀 Quick Start (Desktop)

1. **Download** the appropriate installer for your OS from [Releases](https://github.com/Hasinur3813/metacsv-studio-releases/releases/latest).
2. **Install** and launch **MetaCSV Studio**.
3. **Open or Drag & Drop** any `.csv` file into the workspace.
4. **Inspect & Edit** headers, data types, column descriptions, and values.
5. **Save / Export** your updated dataset and schema.
